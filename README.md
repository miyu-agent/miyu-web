# Miyu web UI

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This repository is Miyu's web UI, which lets you use Miyu in a browser. The web program `miyu-web` serves the page files and translates the browser's WebSocket connection into the core's protocol. By default it only listens on a local port; you can open it to the local network in `Settings → General → Access`.

The core lives in [miyu-agent/miyu](https://github.com/miyu-agent/miyu). This repository pins one commit of the core through a git dependency in `Cargo.toml`, and uses the core's features only through the `miyu-client` crate that the core provides.

For how to use it, see [Web interface](https://github.com/miyu-agent/miyu/blob/main/docs/en/guide/heads/web.md) in the manual; for deploying it to a server and opening it from other computers, see [Keeping it running, and servers](https://github.com/miyu-agent/miyu/blob/main/docs/en/guide/service.md).

## What is in the repository

This section lists the directories in the repository, what each one contains, and the matching design notes.

| Directory | Contents | Design notes |
|---|---|---|
| `crates/miyu-web` | The web program, which provides the two commands `miyu-web serve` and `miyu-web open` | `docs/blueprint/web-module.md` |
| `crates/miyu-webserve` | The lower layer of the web port: serves the page files, checks `Host` and `Origin`, and passes `/ws` through to the core unchanged | `docs/blueprint/webserve.md` |
| `web-demo/` | The pages. They are written in plain JavaScript, organized as ES modules, with no framework and no build step. See `web-demo/README.md` for how to run them | `docs/blueprint/web.md`, `web-ui.md` |
| `webui/` | The web UI's package (id `webui`, settings key prefix `web`), which contains the manifest, the constants file `web.json` and the matugen templates | |

There are two ways to install `webui/`: when a new version is released, it is installed together with the core into `packages/webui/` in the resources directory; or you can pack it with `tools/pack-web.py` into the package file `webui-<version>-<system>.miyu` and install it from a package source.

To release a new version, push a `v<version>` tag. After the push, `.github/workflows/release.yml` builds one package per system with the official packaging template and uploads them to the releases page. The version number is written in two places, `Cargo.toml` and `webui/package.toml`, and the two must be the same.

## Using it on other devices

After you turn on `Local network access` in `Settings → General → Access` and set an access password, phones and computers on the same local network can open the web UI with this computer's address and port. The settings page shows the URL.

> Local network access uses plain HTTP without encryption: people on the same network can see the access password, the login token and the conversation. Only turn it on in a network you trust (for example, your own home). To use it away from home or on a network you do not trust, first connect back home through [Tailscale](https://tailscale.com/) or [WireGuard](https://www.wireguard.com/) and then open it, so that the traffic is encrypted inside the tunnel.

Connections opened through a reverse proxy on this computer (for example nginx or cloudflared) are always treated as other devices: they must enter the access password, and features that only work on this computer (such as choosing a directory on this computer or reading its files) are not available. Keep the following in mind when you use a reverse proxy:

- The proxy must add forwarding headers (for example `Forwarded`, `X-Forwarded-For`, `X-Real-IP`); with nginx you need to write these headers into the configuration.
- The web program only accepts requests whose `Host` is `127.0.0.1`, `localhost` or `[::1]` plus a port; when it listens on the local network, it also accepts this computer's IP plus a port. It does not accept domain names.
- `/ws` only accepts connections whose `Origin` is `http://` plus one of the addresses above.
- If the proxy serves the pages under its own domain name or over HTTPS (including the HTTPS address provided by `tailscale serve`), the requests are rejected (403).

> **Plain TCP forwarding without forwarding headers cannot be recognized as another device**. To the web program, connections forwarded in through `ssh -L` port forwarding, `socat`, `tailscale serve --tcp` and similar methods are this computer itself: anyone who opens the web UI through them can read the files on this computer and can change the access password without entering the old one. Do not use these methods to open the web UI to other people; you may do this only when you are the only user and the device at the other end is also your own.

## Testing

This section shows how to run the tests. Run:

```sh
cargo test
MIYU_RESOURCES=<core checkout>/resources node --test 'web-demo/tests/**/*.test.js'
cargo test --manifest-path web-demo/bridge/Cargo.toml
cargo xtask licenses
```

- The pure-logic tests of the pages need the core's shipped resources (the text shown in the interface). `<core checkout>` is a checkout of the core repository, and its commit must be the same as the one pinned in `Cargo.toml`.
- `cargo xtask licenses` checks the third-party dependencies used on the four released platforms and confirms that their licenses can all be distributed together with AGPL-3.0-or-later; the check is implemented in `xtask/`.
