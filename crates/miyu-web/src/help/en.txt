Usage: miyu web [options]

Open the web interface: start it if it is not running, then open it in a
browser

Options:
      --port <port>  Port the web interface listens on this time (if not
                     running; default: 8300)
      --print        Print the address without opening a browser
      --format <format>
                     Print as text or json (json does not open a browser)
      --reset        Open with a one-time code to reset the access password
      --logout       Sign out every browser
      --package <id> Open this package's page under Backstage
      --session <id> Open this session
      --settings [<page>]
                     Open Settings; access opens Access under General
      --stop         Stop the web interface (the core keeps running)
  -h, --help         Print help
